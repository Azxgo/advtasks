# AdvTasks

AdvTasks es una plataforma de gestión de tareas que funciona como una ToDo List personal, incorporando caracteristicas inspiradas en sistemas de progresion de los videojuegos RPG.

La aplicación permite organizar las actividades diarias, establecer atributos y dificultades para las tareas y llevar un seguimiento del progreso mediante estadísticas.

## Demo

https://advtasks.vercel.app/

> ⚠️ El backend utiliza un servicio gratuito. La primera carga puede tardar unos segundos.

# Características

-👤 Creación de usuarios y acceso como invitado.
-🤖 Creación inmediata de tareas.
-✏️ Edición de las características de una tarea, como nombre, hora, estado y atributos.
-📋 Creación de subtareas dentro de una tarea.
-🎯 Sistema de dificultad y atributos para las tareas.
-📅 Navegación entre las tareas del día y el calendario.
-🔄 Sistema automático de cambios de estado.
-⚙️ Automatización de tareas.
-📊 Registro automático de estadísticas diarias al finalizar el día.
